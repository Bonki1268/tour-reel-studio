### V2 B1 照片合成＋圖生影片（#2）
- 實景照：3 張手機直拍照（4284×5712，HEIC 轉 JPEG）：熱蘭遮城城垣殘蹟、安平古堡石碑、白色瞭望塔
- 流程：置中裁成 9:16（720×1280）→ 依擺放參數疊上去背角色（x、y＝腳底中心，scale＝角色高度÷畫面高度）→（可選）Grok 精修 → Seedance 2.5 圖生影片 4 秒
- 同一張城垣照、同一擺放的比較（`spikes/higgsfield/outputs/v2/`）：
  - 粗合成直接當首幀：320.4 秒；背景完整保留，角色光線偏攝影棚、無接地陰影；抱拳禮變成雙手交叉
  - Grok 精修後當首幀：精修 23.5 秒＋影片 278.7 秒；構圖、角色位置與五官服裝保留，加上方向與陽光一致的接地投影；抱拳禮正確
- 可接受的構圖限制：
  1. 角色腳底必須落在照片中可站立的地面；第一次把 s2 放在石碑基座的垂直石面上，看起來懸空，改成站在基座平台上才自然
  2. 角色不可遮住地標文字與主體（石碑字、瞭望塔）
  3. 仰角照片（瞭望塔）可用，但角色是平視拍攝，透視略不一致
- 失敗案例：沒有 API 失敗。本機去背第一次使用較大的容許值時誤刪白領口與脖子，已改為「四角 flood fill＋只在畫面底部處理接地陰影」
- 注意：Seedance 圖生影片沒有 aspect_ratio 參數，輸出構圖跟隨首幀；720p 上限表示 1080×1920 成品需放大
